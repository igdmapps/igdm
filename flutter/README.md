# Flutter IGdm Client

This is a Flutter client sample for the IGdm API server.

## Requirements

- Flutter SDK installed and on your PATH
- The IGdm API server running at `http://localhost:4000`

## Run

1. Open a terminal in `flutter/`.
2. Run `flutter pub get`.
3. If this is the first Flutter project setup, run `flutter create .` to generate platform files.
4. Run `flutter run`.

## Notes

- The client uses `http` to communicate with the backend.
- The service is intentionally minimal; extend it with real chat UI and media support.
- If Flutter is not installed locally, install it from https://flutter.dev/docs/get-started/install.
